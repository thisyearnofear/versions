# Pilot Program Agreement — DRAFT (for counsel review)

> **Status:** Draft for counsel review — not legal advice.
> **Parties:** VERSIONS (Persidian) + [Artist Name] + [Creator(s)]
> **Purpose:** Authorize selected creators to produce derivative versions
> of one rights-controlled song; VERSIONS provides curation, matching,
> and per-use settlement.

**VERSIONS** — Persidian, operator of the VERSIONS platform.
**Artist** — [Name], rights holder of the Source Work (both master

composition license).
**Creator** — an invited producer/creator who submits a Version.
**Source Work** — "[Song Title]" (MusicBrainz ID: [MBID]).

## 2. Scope of Authorization

### 2.1 Permitted Transformations

The Artist grants Creators permission to produce Versions using the
following transformations **only**:

- [ ] Alt-vocals (re-recorded vocals over existing instrumental)
- [ ] Remix (rearranged instrumental, same or different structure)
- [ ] Mood flip (tempo/key change, different emotional tone)
- [ ] Other: _______________

**Prohibited without separate written consent:**
- [ ] Lyrics rewrite or replacement
- [ ] Using the Artist's original vocals as a source element
- [ ] Model training / AI voice synthesis from the Artist's vocal stems
- [ ] Commercial release on streaming platforms without VERSIONS' approval
- [ ] Defamatory, hateful, or illegal content

### 2.2 Approved Assets

The Artist shall provide (or license to Creators) the following assets:

- [ ] Original vocal stems (format: _____)
- [ ] Tempo/key reference documentation
- [ ] Other: _____

## 3. Creator Obligations

### 3.1 Attribution

Every Version shall credit the Artist as follows:

> "Originally by [Artist Name] — Version by [Creator Name] via VERSIONS"

Attribution appears in the VERSIONS listing, any metadata files, and
any public-facing description.

### 3.2 Provenance

Creators shall document in VERSIONS:

- Tools used (e.g., "re-recorded vocals with Ableton, mixed in Pro Tools")
- Source versions/stems used (for traceability)
- Any third-party samples or licensed material incorporated

### 3.3 Submission Process

1. Creator submits Version audio and provenance metadata to VERSIONS.
2. VERSIONS verifies that the submission complies with the Permitted
   Transformations and asset usage terms.
3. Artist reviews each submission within 7 days and approves or
   rejects (rejection is final for that version).
4. Approved Versions proceed to rating and matching.

---

## 4. Rights & Ownership

### 4.1 Master Recording

- Each new master recording of a Version is owned by the **Creator**
  who produced it.
- Creator grants VERSIONS a **non-exclusive, perpetual, royalty-bearing**
  license to host, distribute, and synchronize the Version through
  VERSIONS and to commercial partners under the terms of this Program.
- Creator grants a **non-exclusive, perpetual** license to VERSIONS to
  display attribution, metadata, and settlement information for the
  Version.

### 4.2 Composition / Publishing

The Artist represents and warrants they control the composition rights
for the Source Work OR have obtained all necessary licenses to authorize
derivative compositions from co-writers/publishers. If the Artist does
not control 100% of composition rights, they shall provide evidence of
licensing to co-writers.

### 4.3 Artist Retained Rights

Nothing in this Program transfers ownership of the Artist's master
recording or composition to VERSIONS or Creators.

## 6. Revocation & Takedown

### 6.1 Artist Revocation

The Artist may revoke authorization for any Version at any time by
notifying VERSIONS in writing. REVOKED Versions:

- Remain in the VERSIONS catalog with "[REVOKED]" status
- Cannot be newly licensed
- Already-settled uses remain finalized
- All royalty rights terminate for future uses

### 6.2 Creator Revocation

A Creator may withdraw their Version at any time before it is licensed,
with no further obligation.

### 6.3 Takedown Triggers

VERSIONS reserves the right to takedown a Version (without artist
request) if it:

- Contains uncleared third-party samples
- Violates content policies (hate speech, illegal activity, etc.)
- Contains misleading attribution or provenance claims

---

## 7. Content Standards

Versions must not contain:

- Hate speech, harassment, or discriminatory content
- Misleading claims about Artist endorsement (unless explicitly stated)
- Defamatory statements about the Artist or third parties
- Pornographic or explicit content (unless the Artist opts in to mature content)
